## 我的工作方法

**业务问题 → 方案设计 → MVP → 评估 → 交付**

先明确业务目标、用户和约束，再设计最小可行方案；通过快速实现验证关键假设，用测试与评估数据判断效果，最后补齐文档、质量保障和交付边界。
